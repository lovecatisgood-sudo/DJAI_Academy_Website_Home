# Original Background Removal Engine — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the AGPL-licensed `@imgly/background-removal` dependency with a first-party, self-hosted background-removal engine built on permissively-licensed components, then fix the preview bug, privacy copy, and SEO of the tool page.

**Architecture:** We write our own inference pipeline — image → tensor → ONNX segmentation model → alpha mask → transparent PNG — running entirely in the browser on `onnxruntime-web` (MIT). The neural network weights are U²-Net (Apache-2.0), self-hosted from our own origin instead of a third-party CDN. The public entry point keeps the exact `remove(image, options)` signature the existing `app.js` already calls, so the swap is invisible to the rest of the app.

**Tech Stack:** Vanilla ES modules, `onnxruntime-web` (MIT), U²-Net `u2netp.onnx` (Apache-2.0), esbuild, `node:test`, Playwright (already present in the sibling Academy repo).

---

## Context: why this work exists

Three findings from the 2026-08-06 investigation drive this plan:

1. **Licensing.** `@imgly/background-removal` is **AGPL-3.0** (verified from `LICENSE.md` in `imgly/background-removal-js`; npm reports only `"SEE LICENSE IN LICENSE.md"`). It is shipped to every visitor of a commercial, ad-supported site, while `djai-image-resizer/package.json` declares `"license": "UNLICENSED"`. The model it runs is *not* IMG.LY's — ISNet/DIS is Apache-2.0. Only the wrapper is AGPL.
2. **The preview bug.** The tool works correctly — a real photo produced 51.5% fully-transparent pixels — but `#compare-view` stacks the transparent result directly over the untouched original at identical geometry, so the removed background shows through pixel-perfectly and the result looks unchanged. `app.js:869` sends every single-image run to that broken view.
3. **Third-party runtime dependency.** ~67 MB of model + wasm is fetched from `staticimgly.com` on first use, contradicting the page's "Private & local" claim and creating a silent single point of failure.

## Global Constraints

- **No AGPL code in the shipped bundle.** When this plan is complete, `@imgly/background-removal` must be absent from `package.json`, `package-lock.json`, and `public/vendor/`.
- **No third-party runtime CDN.** All model and wasm assets must be served from `www.djai.academy`. The existing test `public image-tool code has no donor canonical or runtime CDN` is extended to enforce this.
- **Every dependency permissive.** Only MIT / Apache-2.0 / BSD. Verified so far: `onnxruntime-web` MIT, U²-Net Apache-2.0, DIS/ISNet Apache-2.0, BiRefNet MIT.
- **Attribution is required.** Apache-2.0 requires attribution. A `NOTICE` file plus a visible on-page credit for the model authors must ship. Building it ourselves does not mean pretending the model is ours.
- **`public/vendor/` is gitignored** and generated by `npm run build`. Model assets go there — never committed to git.
- **Bilingual parity.** Every user-facing string must ship in Thai and English. Thai is the default locale; `/en/` is the English variant.
- **The public engine signature is frozen:** `remove(image: Blob, options?: { progress?: (key: string, current: number, total: number) => void }) => Promise<Blob>`. `app.js` already depends on this exact shape at `app.js:819`.
- **No push to `main` without explicit approval.** Hostinger auto-deploys on push; pushing IS deploying to production.

```js
// scripts/fetch-models.mjs
import { createHash } from "node:crypto";
import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";

const projectDir = join(dirname(fileURLToPath(import.meta.url)), "..");
const vendorDir = join(projectDir, "public", "vendor");
const REMBG = "https://github.com/danielgatis/rembg/releases/download/v0.0.0";

// Weights: U^2-Net, Apache-2.0 (github.com/xuebinqin/U-2-Net).
// Mirrored by the MIT-licensed rembg project; the weights' own licence is Apache-2.0.
export const MODEL_SOURCES = [
  { name: "models/u2netp.onnx", url: `${REMBG}/u2netp.onnx`, bytes: 4574861, sha256: "REPLACE_ME" }
];

const download = async (source) => {
  const target = join(vendorDir, source.name);
  mkdirSync(dirname(target), { recursive: true });
  if (existsSync(target)) {
    const digest = createHash("sha256").update(readFileSync(target)).digest("hex");
    if (digest === source.sha256) return;
  }
  const response = await fetch(source.url);
  if (!response.ok) throw new Error(`${source.url} -> HTTP ${response.status}`);
  const buffer = Buffer.from(await response.arrayBuffer());
  const digest = createHash("sha256").update(buffer).digest("hex");
  if (process.env.DJAI_RECORD_CHECKSUMS === "1") {
    console.log(`${source.name}  bytes:${buffer.byteLength}  sha256:${digest}`);
  } else if (source.sha256 !== digest) {
    throw new Error(`checksum mismatch for ${source.name}: expected ${source.sha256}, got ${digest}`);
  }
  writeFileSync(target, buffer);
};

export const fetchModels = async () => {
  for (const source of MODEL_SOURCES) await download(source);
};

if (import.meta.url === `file://${process.argv[1]}`) await fetchModels();
```

```js
// src/engine/preprocess.mjs

// Converts resized RGBA bytes into the channel-first float tensor the
// segmentation models expect. U^2-Net scales by the image's own maximum
// value before applying ImageNet mean/std; ISNet uses a flat /255.
export const toTensor = (rgba, size, model) => {
  const pixels = size * size;
  const tensor = new Float32Array(pixels * 3);

  let max = 0;
  if (model.scaleByMax) {
    for (let i = 0; i < pixels; i += 1) {
      const o = i * 4;
      if (rgba[o] > max) max = rgba[o];
      if (rgba[o + 1] > max) max = rgba[o + 1];
      if (rgba[o + 2] > max) max = rgba[o + 2];
    }
  }
  const divisor = model.scaleByMax ? (max || 255) : 255;

  for (let i = 0; i < pixels; i += 1) {
    const o = i * 4;
    tensor[i]              = (rgba[o]     / divisor - model.mean[0]) / model.std[0];
    tensor[pixels + i]     = (rgba[o + 1] / divisor - model.mean[1]) / model.std[1];
    tensor[pixels * 2 + i] = (rgba[o + 2] / divisor - model.mean[2]) / model.std[2];
  }
  return tensor;
};
```

```js
// src/engine/postprocess.mjs

// U^2-Net and ISNet emit an unbounded single-channel saliency map. The
// reference implementations rescale it to [0,1] by its own min and max
// before use; we do the same and quantize straight to 8-bit alpha.
export const toMask = (output) => {
  let min = Infinity;
  let max = -Infinity;
  for (let i = 0; i < output.length; i += 1) {
    if (output[i] < min) min = output[i];
    if (output[i] > max) max = output[i];
  }
  const range = max - min;
  const mask = new Uint8ClampedArray(output.length);
  if (range === 0) return mask;
  for (let i = 0; i < output.length; i += 1) {
    mask[i] = Math.round(((output[i] - min) / range) * 255);
  }
  return mask;
};
```

```js
// src/engine/remove.mjs
import * as ort from "onnxruntime-web";
import { MODELS, DEFAULT_MODEL } from "./model-config.mjs";
import { toTensor } from "./preprocess.mjs";
import { toMask } from "./postprocess.mjs";

const assetBase = () => new URL("vendor/", document.baseURI).toString();

// Single-threaded WASM: the site is not cross-origin isolated, so
// SharedArrayBuffer is unavailable and threads would silently fall back anyway.
ort.env.wasm.numThreads = 1;
ort.env.wasm.simd = true;

let sessionPromise = null;

const loadSession = (model, onProgress) => {
  if (sessionPromise) return sessionPromise;
  ort.env.wasm.wasmPaths = `${assetBase()}ort/`;
  sessionPromise = (async () => {
    const url = `${assetBase()}${model.file}`;
    const response = await fetch(url);
    if (!response.ok) throw new Error(`model ${response.status}`);
    const total = Number(response.headers.get("content-length")) || 0;
    const chunks = [];
    let loaded = 0;
    const reader = response.body.getReader();
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      chunks.push(value);
      loaded += value.length;
      if (total) onProgress?.("fetch:model", loaded, total);
    }
    const buffer = new Uint8Array(loaded);
    let offset = 0;
    for (const chunk of chunks) { buffer.set(chunk, offset); offset += chunk.length; }
    return ort.InferenceSession.create(buffer, { executionProviders: ["wasm"] });
  })().catch((error) => { sessionPromise = null; throw error; });
  return sessionPromise;
};

const drawToSize = (source, width, height) => {
  const canvas = document.createElement("canvas");
  canvas.width = width;
  canvas.height = height;
  const ctx = canvas.getContext("2d", { willReadFrequently: true });
  ctx.imageSmoothingEnabled = true;
  ctx.imageSmoothingQuality = "high";
  ctx.drawImage(source, 0, 0, width, height);
  return { canvas, ctx };
};

export const remove = async (image, options = {}) => {
  const model = MODELS[options.model || DEFAULT_MODEL];
  const session = await loadSession(model, options.progress);
  const bitmap = await createImageBitmap(image);

  try {
    // 1. Resize to the model's input square and normalize.
    const { ctx: smallCtx } = drawToSize(bitmap, model.size, model.size);
    const rgba = smallCtx.getImageData(0, 0, model.size, model.size).data;
    const tensor = new ort.Tensor("float32", toTensor(rgba, model.size, model), [1, 3, model.size, model.size]);

    // 2. Run inference; U^2-Net exposes several side outputs, d0 is first.
    const outputs = await session.run({ [session.inputNames[0]]: tensor });
    const mask = toMask(outputs[session.outputNames[0]].data);

    // 3. Paint the mask onto a canvas so the GPU resamples it back up.
    const maskCanvas = document.createElement("canvas");
    maskCanvas.width = model.size;
    maskCanvas.height = model.size;
    const maskCtx = maskCanvas.getContext("2d", { willReadFrequently: true });
    const maskImage = maskCtx.createImageData(model.size, model.size);
    for (let i = 0; i < mask.length; i += 1) {
      const o = i * 4;
      maskImage.data[o] = maskImage.data[o + 1] = maskImage.data[o + 2] = mask[i];
      maskImage.data[o + 3] = 255;
    }
    maskCtx.putImageData(maskImage, 0, 0);

    // 4. Composite the upscaled mask into the original's alpha channel.
    const { canvas: outCanvas, ctx: outCtx } = drawToSize(bitmap, bitmap.width, bitmap.height);
    const full = outCtx.getImageData(0, 0, bitmap.width, bitmap.height);
    const { ctx: scaledMaskCtx } = drawToSize(maskCanvas, bitmap.width, bitmap.height);
    const scaled = scaledMaskCtx.getImageData(0, 0, bitmap.width, bitmap.height).data;
    for (let i = 0; i < bitmap.width * bitmap.height; i += 1) {
      full.data[i * 4 + 3] = scaled[i * 4];
    }
    outCtx.putImageData(full, 0, 0);

    return await new Promise((resolve, reject) => {
      outCanvas.toBlob((blob) => blob ? resolve(blob) : reject(new Error("encode failed")), "image/png");
    });
  } finally {
    bitmap.close?.();
  }
};
```
