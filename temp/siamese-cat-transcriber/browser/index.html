ไม่มีอีเมล และไม่มีการอัปโหลดไฟล์ไปยัง DJAI

ไฟล์ถูก decode, แปลงเป็นข้อมูลเสียง และถอดข้อความใน browser ของคุณเอง โดยใช้ CPU หรือ GPU ของอุปกรณ์ที่รองรับ โมเดล AI ต้องดาวน์โหลดจาก Hugging Face ในครั้งแรกตามการตั้งค่า cache ของ browser

01

เลือกไฟล์ในเครื่อง

ไฟล์ไม่ได้ถูกส่งไปยังเซิร์ฟเวอร์ DJAI เพื่อถอดเสียง

02

AI ทำงานใน browser

WebGPU จะถูกใช้เมื่อพร้อมใช้งาน และ browser จะ fallback ไปยัง CPU เมื่อจำเป็น

03

ตรวจและดาวน์โหลด

แก้ข้อความตามเวลา แล้วส่งออกไฟล์ที่ต้องการจากอุปกรณ์ของคุณ

WORKFLOW

ก่อนจะใช้ transcript ในงานจริง ควรตรวจอะไรบ้าง?

1

เลือกโมเดลที่เหมาะกับเครื่อง

เริ่มด้วย Base หากเป็นครั้งแรก เลือก Tiny เมื่ออินเทอร์เน็ตหรือเครื่องมีข้อจำกัด และ Small เมื่อยอมรอเพื่อความแม่นยำเพิ่มขึ้น

2

ปล่อยให้ tab นี้ทำงาน

การถอดเสียงใช้ RAM และพลังประมวลผลของอุปกรณ์ อย่าปิด tab และเริ่มด้วยคลิปสั้นหากยังไม่เคยใช้มาก่อน

3

ตรวจชื่อและคำสำคัญ

ชื่อเฉพาะ สำเนียง เสียงรบกวน และคนพูดทับกันอาจผิดได้ แก้ข้อความก่อนเผยแพร่ซับไตเติลหรือคำอ้างอิง

HELP BEFORE YOU START

คำถามเกี่ยวกับการถอดเสียงวิดีโอ

ต้องสมัครสมาชิกหรือให้อีเมลไหม?

ไม่ต้อง ไม่มี account, email หรือ credit card สำหรับเริ่มใช้เครื่องมือนี้

ไฟล์ออกจากอุปกรณ์หรือไม่?

ไม่ ไฟล์ถูกประมวลผลใน browser ของคุณและไม่ถูกอัปโหลดไปยัง DJAI การดาวน์โหลดโมเดลในครั้งแรกจะเชื่อมต่อกับ Hugging Face เพื่อรับไฟล์โมเดล

ทำไมใช้ครั้งแรกนาน?

browser ต้องดาวน์โหลดโมเดล AI และเตรียมไฟล์เสียงก่อน หลังจากนั้น browser อาจใช้ model cache ที่เก็บไว้ได้ ขนาดและระยะเวลาขึ้นกับโมเดล อุปกรณ์ และ browser ของคุณ

transcript ถูกต้องสมบูรณ์เสมอไหม?

ไม่ ตรวจคำสำคัญ ชื่อเฉพาะ สำเนียง และช่วงที่มีเสียงรบกวนก่อนใช้งานสำคัญ
